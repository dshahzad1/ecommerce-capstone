# E-Commerce Web Application (Capstone)

A full-stack e-commerce platform featuring a dynamic product catalog, secure database backend, and inventory tracking.

## Features
- **Dynamic Catalog:** Pulls product information, pricing, and live inventory levels directly from a MySQL database.
- **Backend Inventory Management:** Relational database schema designed for efficient product and stock tracking.
- **Clean UI:** Responsive web interface styled for seamless user experience across devices.

## Technologies Used
- HTML5 / CSS3
- PHP
- MySQL / phpMyAdmin
